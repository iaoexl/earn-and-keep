# 商业与投资认知库（earn-and-keep）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 一个以「正当赚钱 + 守住钱」为骨架的商业与投资认知库。把商业逻辑、搞钱路径与投资操作系统重构成**可落地**的体系：从认知定位到行动方法，再到风控与复盘，逐板块递进，配套自检清单与可执行工具。
> 
> 本仓库是商业认知与投资知识的整理、汇编与重构，属学习研究资料。每篇笔记自足、格式统一，打开即用；脚本与示例配置统一收口在 `tools/`，开箱即跑。
